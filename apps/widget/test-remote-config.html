Widget — stored config test

This page is the counterpart to test.html. That one hardcodes almost every data-* attribute, and attributes always beat stored config — so it can't show you whether the dashboard settings are working.

This page sets only data-client-id and data-api-url. Everything you see — title, tagline, colours, the rotating teaser bubbles, and the quick-reply buttons inside the panel — comes from that client's saved settings, fetched from /widget-config/:clientId at load.

To test a different client: swap the data-client-id below. The widget should completely rebrand with no other change — same script, same Worker.
To test the offline fallback: stop the API and reload. The widget must still render, with built-in defaults, rather than disappearing. A dead API should never leave a blank corner on a client's site.
